#💰 Student Expense Tracker

A beginner-friendly Python application for recording, managing, and analyzing student expenses.

✨ Features

- ➕ Add expenses
- 🏷️ Categorize expenses
- 📋 View recorded expenses
- 💰 Calculate total spending
- 💾 Save expenses to a file
- 🔄 Load saved expenses when the program starts
- 📊 View spending by category
- ✅ Validate expense amounts

🛠️ Technologies & Concepts

- Python
- Lists
- Dictionaries
- Loops
- Conditional statements
- User input
- File handling
- Exception handling
- Input validation
- Basic data processing

🚀 How It Works

1. Start the program.
2. Choose an option from the menu.
3. Add an expense and select its category.
4. The expense is saved to "expenses.txt".
5. Previously saved expenses are loaded when the program starts.
6. View your total spending or spending by category.

▶️ How to Run

Make sure Python is installed.

python expense_tracker.py
